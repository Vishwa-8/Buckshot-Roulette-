# 🔫 Buckshot Roulette

A console-based shooting game developed in **C language** as a programming project.

The project is inspired by the concept of *Buckshot Roulette* and focuses on implementing game logic, randomization, user interaction, and sound effects using C.

## 🎮 About the Project

Buckshot Roulette is a turn-based game where the player interacts with a randomized set of shotgun rounds.

The project was created to practice programming concepts in C while building an interactive game with a simple console-based interface.

## ✨ Features

- 🎲 Randomized game logic
- 🔫 Turn-based gameplay
- 🎯 Interactive player choices
- 🔊 Gunshot sound effect
- 🔄 Reload sound effect
- 💻 Console-based interface
- 🧠 Game logic implemented using C

## 🛠️ Technologies Used

- **C**
- **C Standard Library**
- **Windows Console**
- **WAV audio files**
